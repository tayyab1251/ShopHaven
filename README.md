# E-Commerce Website Store

This is a fully functional e-commerce website store built with PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap. It allows users to browse products, add items to the cart, and manage purchases. The admin dashboard enables product management, including adding, updating, and deleting products.

## Features

- User-friendly product browsing interface  
- Add-to-cart functionality with quantity updates  
- Admin dashboard for product management (CRUD operations)  
- Responsive design using Bootstrap  
- MySQL database integration for data storage 
- Admin Authentication  

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap-5 
- **Backend:** PHP  
- **Database:** MySQL

   ```bash
   git clone https://github.com/tayyab1251/ShopHaven.git
   
2. Import the database:  
   - Open phpMyAdmin and import the `database/ecommerce_store.sql` file.

Update the database credentials in the configuration file (e.g., config.php).
Run the project on a local server (XAMPP, WAMP, or similar).
